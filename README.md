# design-system

One source for how LITSA projects look: color, type and spacing tokens, fonts, the torch and wordmark, web components, and the print and social renderers.

`tokens/tokens.json` is the single source. Build scripts turn it into CSS variables, a Python module for the flyer and deck scripts, and the spreadsheet palette.
